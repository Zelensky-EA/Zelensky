# AP Chemistry Navigator

GitHub Pages-ready React/Vite course navigator modeled on the AP Biology Navigator.

## Included

- Complete 2025 AP Chemistry CED tracker: 9 units and 91 topics
- Persistent Yes / Maybe / No self-assessment progress stored in the browser
- 2027 AP Chemistry exam format and date
- Local copies of the official CED and four-page exam reference sheet

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

Push the folder contents to a repository and enable GitHub Pages with GitHub Actions. The included workflow builds and deploys the site.
